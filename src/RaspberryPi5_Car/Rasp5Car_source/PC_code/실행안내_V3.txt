위험 구역 탐사 로봇 제어 시스템 V3(20) 실행 안내
================================================

1. 변경 사항
- 검색 패널: 리스트박스 너비 281→300px, 높이 410→454px 확장
- 리스트박스에서 안전모 미 착용을 포함한 16개 전체 항목을 스크롤 없이 표시
- 스크롤바 제거; 검색 시작/중지와 검색 안내 글자를 아래로 재배치
- 탐사 이력 보기 버튼을 11px 아래로 이동, 로고 하단 y=1030 정렬 유지
- 리스트박스 16개 항목: 기존 15개 + '안전모 미 착용' (빨간 글씨)
- '사람' 검색: 기존 yolo11n.pt (COCO 사람 클래스)만 사용. 안전모와 무관하게 사람을 발견하면
  '사람을 발견했습니다.' 안내 및 차량 정지
- '안전모 미 착용' 검색: 사전학습된 안전모 전용 YOLO 모델만 사용.
  'Helmet'은 정상으로 취급하고, 'Head'(맨머리) 검출 시에만 위반 후보로 처리합니다.
  유사 위치의 Helmet/Head 중복 검출을 필터링하고 같은 대상이 연속 3회 확인되면
  차량 정지 + '안전모를 착용해 주세요.' 안내 + 사진 표시
- 기존 벽면 균열/노출 철근/누수 흔적은 기존 사진 특징 비교 유지
- 기존 주행 제어, 초음파 안전 정지, 한국어 여성 음성, 사진 저장 승인, SQLite 조회/삭제 유지
- 발견 사진 창: [닫기] → [예] 선택 시에만 DB + 전체 사진 + 부분 사진을 저장
  [아니요]: 저장 없이 닫기, [취소]: 창을 유지하고 이동 잠금 유지
- DB: '사람'은 정상 / '안전모 미 착용'은 이상. 일반 12종 정상/건축 결함 3종 이상
- '탐사 이력 보기' → 행 선택 → [사진 보기]에서 저장된 두 사진 표시
- SQL 레코드 고유 id는 보존, 테이블 표시 번호는 1부터 순서대로 부여

2. 기존 프로그램 폴더에 압축 해제
- 반드시 기존 images/button_back1.png와 images/smartICT.png를 보존하세요.
- 기존 exploration_history.db, captures/ 폴더도 삭제하지 마세요.
- 기존 사진 비교 데이터(models/structural_defects.pt)는 ZIP에 포함되어 있습니다.
- 신규 models/helmet_detection.pt 파일은 ZIP에 포함되어 있지 않습니다.
  온라인에서 사용자가 내려받아야 합니다.

3. Windows PowerShell (프로젝트 폴더에서 실행)
py -m pip install websocket-client Pillow ultralytics opencv-python torch edge-tts
py download_helmet_model.py
py test_helmet_photos.py
py "car_tk_clientV3(20).py"

  * 이미 models/helmet_detection.pt가 있다면 다운로드 스크립트는 모델의 클래스를 검사하고 유지합니다.
  * 모델이 없다면 아래 공개 GitHub 저장소 best.pt를 받아서 설치하고 클래스를 검사합니다.
    https://github.com/dhanu65/Emagesoft-safety-helmet-detection/blob/main/best.pt
  * 네트워크 차단으로 다운로드에 실패하면 직접 best.pt를 다운로드하여
    models/helmet_detection.pt 로 저장하세요.
  * 사용할 외부 .pt 모델은 출처를 신뢰할 수 있어야 합니다.
  * test_helmet_photos.py는 제공하신 4장(착용 2장, 미착용 2장)의 판정을 실제 모델로 시험하고
    helmet_test_results 폴더에 표시 결과 이미지를 저장합니다.

4. 권장 시험 순서
A. '사람' 선택 → 검색 시작 → 안전모 착용자/미착용자 모두 사람으로 인식되는지 확인
B. '안전모 미 착용' 선택 → 검색 시작 → 안전모 착용자를 보여줄 때 경고가 없는지 확인
C. 다른 사람의 안전모 미착용 영상을 보여주어 연속 감지 시 정지/음성 안내 확인
D. 발견 창 [닫기]→[예]→[탐사 이력 보기]→행 선택→[사진 보기] 확인
E. '아니요'는 DB에 저장되지 않는지, '취소'는 이동 잠금이 계속 유지되는지 확인
F. 실제 로봇에서 정지 확인 메시지와 장애물 정지 기능을 추가 검증

5. 안전과 한계
- 전용 모델: Helmet/Head/Person 데이터를 학습한 YOLO11n 예시 가중치
- 서버 코드 변경 없음: PC 클라이언트에서만 영상을 분석합니다.
- 본 시스템은 사진에 표시된 사람이 누구인지 이름/신원으로 식별하지 않습니다.
  사람이 찍힌 상반신 사진을 저장하여 사용자가 나중에 확인하는 방식입니다.
- 제공하신 4장만으로 학습한 것이 아닙니다. 별도 공개 데이터셋으로 사전학습된 모델입니다.
- 모델 가중치 파일은 현재 배포 ZIP에 포함되지 않습니다. 설치 후 시험해야 합니다.
- 조명, 각도, 사람의 자세, 영상 지연 등에 따라 놓치거나 잘못 판단할 수 있습니다.
- 사람과 안전모 검출은 인증된 안전 장치가 아니며, 로봇의 비상 정지 기능을 대체하지 않습니다.
